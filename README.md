# Student Result Processing System

## 1. Project Title

Student Result Processing System using Go

## 2. Objective

The objective of this project is to develop a modular command-line application
using Go to process student marks and calculate total, average, grade, and result.

## 3. Features

- Enter student name and roll number
- Enter marks for five subjects
- Calculate total marks
- Calculate average marks
- Calculate grade
- Display Pass or Fail result
- Uses modular programming
- Uses Go packages

## 4. Technologies Used

- Go Programming Language
- Visual Studio Code
- Git and GitHub

## 5. Project Structure

student-result-go/

├── main.go

├── go.mod

├── README.md

├── student/

│   └── student.go

└── result/

    └── result.go

## 6. Modules

### Student Module

The student module stores student details such as name, roll number,
and subject marks.

### Result Module

The result module calculates total, average, grade, and pass/fail status.

## 7. How to Run

Open the project folder in Visual Studio Code.

Open the terminal and run:

go run .

## 10. Conclusion

This project demonstrates how Go can be used to develop a modular
command-line application. It also demonstrates the use of structures,
functions, slices, loops, conditional statements, packages, and
version control using Git and GitHub.
